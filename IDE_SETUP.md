# IDE Setup — Visual Studio (Windows)

1. Download Visual Studio (Community) from:

   https://visualstudio.microsoft.com/downloads/

2. Choose "Visual Studio 2022/2023 Community" and run the installer.

3. In the installer workload selection, enable:
   - .NET desktop development
   - ASP.NET and web development
   - (Optional) Mobile development or Azure workloads if needed

4. After install, open the solution `YAvuzeli.sln` from the repository root.

5. To open from command line after installing Visual Studio, run:

```
start "" "YAvuzeli.sln"
```

6. If you prefer VS Code, ensure the C# and .NET extensions are installed. Visual Studio offers a more integrated WPF designer.
